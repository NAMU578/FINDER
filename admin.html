통합검색기 관리

여기서 저장하면 settings.json 이 커밋되고, 잠시 뒤 검색기에 반영됩니다.

1. 접속

GitHub Fine-grained 토큰(해당 저장소 Contents 쓰기 권한)이 필요합니다. 토큰은 이 브라우저에만 저장되며 저장소에 올라가지 않습니다. 공용 PC에서는 기억하기를 끄고 사용하세요.

2. 장소 표시 설정

장소 체크를 끄면 해당 시트를 아예 불러오지 않습니다. 분류 체크는 그 장소에서 노출할 항목 종류입니다. 날짜는 검색기 상단의 "최근 갱신" 표시에 쓰입니다.

3. 공지 배너

4. 업데이트 내역(패치노트)

최신 날짜가 위로 정렬되어 검색기 하단에 표시됩니다.

5. 저장 전 확인

물품 수를 불러오면 노출 건수를 계산합니다.
